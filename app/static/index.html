How does this work?

A computer model has studied many past orders from this shop. It learned what a typical order looks like: how prices, discounts, shipping, tax and fees usually relate to each other.

When you check an order, the model gives it an unusualness score. A higher score means the order is less like the orders it has seen. If the score passes the alert line, the order is marked "Needs a closer look".

You also get the three things that stand out most about the order compared with a typical one.

An unusual order is not necessarily fraud. A person should always make the final decision.
